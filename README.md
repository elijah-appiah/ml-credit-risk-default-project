# Home Credit Default Risk Prediction

## Overview
This project develops a machine learning pipeline for predicting loan default risk using the Home Credit Default Risk dataset from Kaggle.

The project demonstrates:
- Data preprocessing
- Feature engineering
- Imbalanced classification handling
- Ensemble machine learning
- Explainable AI
- Financial risk analytics

## Models Used
- Logistic Regression
- Random Forest
- XGBoost
- LightGBM

## Key Features
- SMOTE balancing
- SHAP explainability
- ROC-AUC evaluation
- Feature importance analysis
- Production-oriented architecture
